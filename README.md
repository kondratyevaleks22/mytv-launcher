# Мой ТВ — лаунчер для Android TV

Лёгкий главный экран для телевизора в мягком стиле iPhone: светлая, тёмная или автоматическая тема, «Избранное» и все установленные приложения с их настоящими значками.

## Что умеет

- Показывает **все установленные приложения** (Кинопоиск, YouTube, Netflix, VK Видео, Okko, Wink и любые другие) с их значками.
- **Избранное** сверху. При первом запуске туда сами попадают Netflix, Кинопоиск, YouTube, VK Видео, Okko и Wink, если они установлены.
- **Удерживайте OK** (или нажмите кнопку «Меню») на любом приложении: можно добавить его в избранное или убрать, переставить влево/вправо, открыть сведения о приложении.
- **Тема**: светлая, тёмная или «Авто» (с 7:00 до 20:00 светлая, вечером тёмная). Кнопка «Оформление» вверху справа.
- **4 цвета подсветки**: синий, оранжевый, фиолетовый, зелёный.
- Часы, дата и приветствие по времени суток.
- Кнопки Wi‑Fi и настроек телевизора.
- Нет рекламы, рекомендаций и фоновой загрузки — поэтому работает быстро.

## Как получить APK (без программирования)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Создайте новый репозиторий: кнопка **New**, любое имя, например `mytv-launcher`.
3. На странице репозитория нажмите **uploading an existing file** и перетащите туда **всё содержимое** этой папки (вместе со скрытой папкой `.github`). Нажмите **Commit changes**.
   - Если папка `.github` не перетаскивается, создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, и вставьте содержимое одноимённого файла из архива.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–6 минут.
5. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте **MyTV-Launcher** (это zip, внутри `MyTV-Launcher.apk`).

## Как установить на телевизор

Самый простой способ — через флешку:

1. Скопируйте `MyTV-Launcher.apk` на флешку и вставьте её в телевизор.
2. Откройте файл любым файловым менеджером на ТВ (например, **File Commander** или **X-plore** из Google Play).
3. Разрешите установку из неизвестных источников, когда телевизор спросит.

Другие способы: приложение **Send Files to TV** (передача с телефона) или **Downloader** (если загрузите APK куда-нибудь в облако).

## Как сделать главным экраном

Нажмите кнопку **«Домой»** на пульте. Если появится выбор — выберите **«Мой ТВ»** и **«Всегда»**.

На многих телевизорах с Google TV выбора нет, и стандартный экран не даёт себя заменить. Тогда есть два варианта:

- Через компьютер (ADB) отключить стандартный лаунчер:
  ```
  adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
  ```
  Вернуть обратно:
  ```
  adb shell pm enable com.google.android.apps.tv.launcherx
  ```
  Название стандартного лаунчера зависит от модели телевизора.
- Или поставить приложение **Button Mapper** и назначить на кнопку «Домой» запуск «Мой ТВ».

## Для разработчиков

Kotlin + Jetpack Compose, minSdk 21. Открывается в Android Studio как обычный проект. Сборка: `./gradlew assembleRelease`.
